# KEN-JO Industries Homepage Redesign

## Website Overview

KEN-JO Industries Pte. Ltd. supplies, installs, and maintains lifts for residential, public, and commercial spaces in Singapore. The redesigned homepage helps homeowners, building owners, and facilities teams compare lift maintenance contracts and request a proposal.

## Main Improvements

1. **Bring maintenance packages into the homepage.** A hero link takes visitors directly to the maintenance section, where dedicated cards introduce the comprehensive and non-comprehensive packages.
2. **Make coverage easy to compare.** A side-by-side table shows that both packages include preventive maintenance and emergency call-back. It distinguishes how each package typically handles repairs, replacement parts, and labour, with exact coverage and charges governed by the written agreement.
3. **Make quotation requests package-specific.** Each package card opens an email with a prefilled subject for the selected contract. Nearby guidance asks visitors to share the lift type, model, location, number of units, and maintenance requirements. Confirm the destination before publication. The HTML uses contracts@ken-jo.com.sg, while the company profile lists contracts@ken-jo.com.

## Design Improvements

Two consistently structured package cards introduce the options before the comparison table. Prominent quote buttons and a three-step enquiry guide help visitors move from reviewing coverage to requesting a written proposal.
